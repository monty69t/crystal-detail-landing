# Кристалл Детейл — лендинг

Адаптивный сайт детейлинг-студии в Екатеринбурге.

Откройте `dist/index.html` в браузере. Все изображения находятся в `dist/assets/images`; внешних зависимостей нет. HTML — в `dist/index.html`, стили — в `dist/styles.css`, мобильное меню — в `dist/script.js`.

`PROMPT.md` содержит подробный запрос для доработки лендинга. `SOURCES.md` содержит источники стоковых фотографий. Галерея показывает иллюстративные снимки, а не реальные работы студии.
